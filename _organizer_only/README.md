# 主催者向け資料（参加者には配布しない）

このフォルダには、ダミーデータに **意図的に仕込んだ出来事（＝分析で見つけてほしい答え）** と、Excel 帳票の **正解データ** が入っています。
参加者向けに ZIP を配布するときは、このフォルダを含めないでください（`data/` フォルダだけを配布します）。

| ファイル | 内容 |
|---|---|
| [`embedded_scenarios.md`](embedded_scenarios.md) | 仕込んだ出来事・データ品質の課題の一覧（日付・ID・どのデータに現れるか） |
| `expected_outputs/daily_reports_expected.csv` | 07 の日報を 1 つの表にまとめた正解（店舗・日付ごと。POS の値・転記ミスの有無つき） |
| `expected_outputs/purchase_orders_expected.csv` | 07 の発注書を品目マスタに名寄せした正解（発注書・品目ごと） |

審査の際に「記事の分析が仕込んだ出来事を正しく捉えているか」を確認する材料として使えます。
仕込んだ出来事は、天気（気象庁の実測値）や施策の効果と重なって現れるため、記事によって異なる切り口で見つかることがあります。
